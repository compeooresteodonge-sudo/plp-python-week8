Personal Mini-Toolkit
What This Toolkit Does

The Personal Mini-Toolkit is a menu-driven Python program containing three useful tools: a simple calculator, a to-do list, and a number guessing game. The calculator performs basic arithmetic operations, the to-do list allows users to add, view, and remove tasks, and the guessing game lets users guess a secret number.

How to Run
Download or clone this repository.
Make sure Python is installed on your computer.
Open a terminal in the project folder.
Run the following command:
python toolkit.py

Choose an option from the menu and follow the instructions.

Reflection

The hardest part of this project was connecting all three tools to one menu while making sure the menu returned after each tool finished. The part that took the longest to test was handling invalid input because the program should not crash when a user enters something unexpected. I also had to make sure the to-do list changed correctly when tasks were added and removed. Testing each menu option helped me find and correct small problems in the program. I learned that breaking a large program into separate functions makes the code easier to understand and maintain. I also became more comfortable using loops, lists, conditionals, and f-strings together. If I had one more week, I would add more tools such as a unit converter, password generator, or a study timer.
